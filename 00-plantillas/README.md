# Plantillas reutilizables

Este directorio centraliza plantillas para crear nuevas asignaturas con estructura y metadatos consistentes.

## Contenido
- `plantilla-asignatura/`: estructura base de una materia.
- `README-semestre-template.md`: plantilla para documentar semestres e índice de materias.

## Uso recomendado
1. Copiar `plantilla-asignatura/` al semestre correspondiente.
2. Renombrar la carpeta con formato `nombre-de-la-materia`.
3. Actualizar `README.md`, `AGENTE.md` y `METADATOS.md`.
4. Añadir la materia al índice del `README.md` del semestre.
